# 아이콘

`make-icons.py` 가 아이콘을 생성합니다. Pillow 만 있으면 됩니다.

```bash
python3 assets/icons/make-icons.py         # 채택안을 src/icon.png 로 생성
python3 assets/icons/make-icons.py --all   # 시안 전체를 candidates/ 에 생성
```

## 채택안 (N)

차콜 그라데이션 배경 + 오렌지 일시정지 바 + 흰색 `+` 배지.

- **일시정지 바**: 이 확장이 실제로 하는 일(영상을 지우지 않고 멈춘다)을 나타냅니다.
  재생 버튼(삼각형)은 쓰지 않습니다.
- **`+` 배지**: 사용자의 주 조작인 '현재 채널을 블랙리스트에 추가'를 나타냅니다.
  16px 툴바에서도 남도록 크게 잡고, 둘레에 배경색 링을 둘러 본체와 분리했습니다.
- **오렌지**: 차단 오버레이 색(`rgba(230,126,34,.94)`)과 맞췄습니다.
  무채색 배경에서 포인트가 되어 툴바 시인성이 좋습니다.

## 빨강을 쓰지 않는 이유

유튜브 로고의 식별 요소는 '빨간 둥근 사각형 + 흰 삼각형'의 **조합**입니다.
빨강 자체나 둥근 사각형은 독점되지 않으므로 일시정지 바를 쓰면 형태는 겹치지 않습니다.
다만 유튜브 관련 확장이 유튜브의 색과 형태를 그대로 쓰면 공식 제품으로 오인될 여지가
커지므로, 리스크를 낮추는 쪽을 택했습니다. `candidates/icon-L.png` 가 빨강 시안입니다.

## 시안

`candidates/` 에 검토한 안들이 남아 있습니다.
`icon-A~C` 는 세로 프레임 계열, `icon-D~K` 는 일시정지 바 계열(플랫),
`icon-L~O` 는 입체 계열입니다.
